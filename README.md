
# Pixel Pulse

## Design Decisions
1. **Accessible Search Controls:** I chose to wrap the search input in a `<form>` and explicitly link a `<label>` to the `<input>` using the `for` and `id` attributes. This ensures the app is fully accessible to screen readers.
2. **CSS Grid Layout:** I chose to use `display: grid` for the results container. This creates a responsive layout that automatically adjusts the number of columns based on the screen size, making the image gallery look clean on both desktop and mobile devices.


This is a small website where you can search for anything and recieve 20 images as response. It was created as a project and as an assignment in my course. It is purely for learning purposes and is not designed to be used commercially/globally.
